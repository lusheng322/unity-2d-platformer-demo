## 一、接入敌人死亡动画（代码已就绪，只差动画与 Animator）

**代码侧已完成**（`Enemy.cs`）：
- 字段：`Max Health`（默认 5）、`Death Destroy Delay`（默认 1.5 秒）、`Death Bool Name`（默认 `Death`）
- 逻辑：受伤扣血 → 血量归零 → 停止 AI、速度清零、解除冻结、设置 Animator 的 `Death` 布尔 → 延时销毁
- 找不到 `Death` 参数时只打黄色警告并延时销毁（不会报错）

**素材已现成**：`Assets/Graphics/Enemies/Skeleton/Skeleton Dead.png` 已经是 `Sprite Mode = Multiple`，**切好了 19 帧**，不需要再切图。

**你要做的**：
1. 生成死亡动画：
   - `Window → Animation → Animation` 打开动画窗口；
   - 在 Hierarchy 里选中场景中的敌人（骷髅）对象；
   - 在动画窗口点 **Create** → 保存为 `Assets/Animataion/Enemy/EnemyDeath.anim`；
   - 把 `Skeleton Dead.png` 展开后的 **19 个精灵帧全选**，拖进时间轴；
   - 采样率（Samples）调成和原素材一致（一般 10~12），播放预览；
   - 预览完把动画窗口关掉即可。
2. 接进 Animator：双击 `Assets/Animataion/Enemy/Enemy_AC.controller`
   - 左下 **Parameters** → `+` → **Bool** → 名字填 **`Death`**（必须一字不差）；
   - Base Layer 空白处右键 → `Create State → Empty` → 重命名为 **`Death`**；
   - 把 `EnemyDeath.anim` 拖到这个状态上；
   - 右键 **`Any State`** → `Make Transition` → 连到 `Death`；
   - 点这条转换箭头：**取消勾选 `Has Exit Time`**、`Transition Duration = 0`；Conditions 里添加 **`Death == true`**；
   - `Death` 状态**不需要**连回其它状态（对象由代码在延时后销毁）。
3. 参数配置（敌人对象或其 Prefab 上）：
   - `Max Health`：想被打几下就填几（默认 5）；
   - `Death Destroy Delay`：按你的死亡动画时长填，比如动画 1.2 秒就填 **1.3**；
   - `Death Bool Name`：保持 `Death`。
4. 验收：连打敌人 5 下 → 播放死亡动画 → 约 1.3 秒后消失；期间它不再攻击玩家；在黑洞里被冻结时死亡，动画也能正常播放。

> 如果暂时不想做动画：什么都不加也能跑——控制台会给黄色警告，敌人延时后直接销毁。

## 二、工程收尾（10 分钟）

1. **移走 `Assets/RPG.zip`**：它是教程资源包压缩包，留在 Assets 里会让 Unity 每次处理它。建议移到 `D:\UE_project\RPG_资源包\`（.gitignore 里已经忽略它）。
2. **确认构建场景**：`File → Build Settings` 里看看 `Assets/Scenes/SampleScene.unity`（空模板）是不是被加进去了；如果没用到就从列表里移除（**不要直接删文件**，删之前先确认它不在构建列表里）。
3. **确认控制台干净**：切到 Unity 让它重新编译一次，看 Console 有没有红字报错（有就截图发我）。
4. **Inspector 建议值复核**（这些是配置，不是代码）：
   - 场景 `Sword_Skill`：`bounceSpeed` 建议 8~12（原值 2 太慢）；
   - 场景 `Blackhole_Skill`：`blackholeDuration` 1~2（现在只是兜底）、`cooldown` 建议 3~5；
   - 场景 `Crystal_Skill`：`moveSpeed` 确认不是 0（建议 5）、`crystalAmount` 3；
   - `SkillManager`：`crystalSpawnInterval` 0.08（三个水晶的生成间隔，方便你对着效果微调）。

## 四、简历文案（更新版，反映当前功能）

> **2D 平台动作 Demo（个人项目 · Unity 2022 LTS / C#）**
> - 玩家控制：基于 **State 模式**的状态机（Idle/Move/Jump/WallSlide/WallJump/Dash/Attack/CounterAttack/AimSword/CatchSword/Blackhole 等 12 个状态），**动画事件**驱动状态切换
> - 技能系统：`Skill` 基类（冷却 + `IsReady`）+ `SkillManager` 分发 + 各技能 Controller 管理产物生命周期；实现投剑（弹射/穿透/旋转）、分身、水晶、黑洞、冲刺 5 个技能
> - 战斗与敌人：骷髅敌人独立 AI 状态机（Idle/Move/Battle/Attack/Stunned）；玩家与敌人共用 `Entity` 基类（受击闪白、击退、地形检测）；敌人血量与死亡动画
> - 机制改造：将黑洞的 QTE 选择改为"再按一次 R 一键攻击黑洞内全部敌人（等分身演完才收尾）"；水晶改为闪避触发、依次生成 3 个；补齐技能输入的状态门禁
> - 工程实践：`[SerializeField]` 参数化配置、事件解耦、`Docs/` 记录 bug 排查与改造过程
